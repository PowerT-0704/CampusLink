# 岚连 Campus Link v1.4.2

本版本改善密码保护与恢复稳定性。应用内版本、Windows 安装包、README 与独立官网同步更新至 v1.4.2。

- **记住一次，重启继续用**：使用 Electron `safeStorage` 系统加密保存密码，写入前验证能够解密；可用密码只在主进程内存中复用。保持原应用标识和数据目录。
- **兼容升级与暂时故障**：启动时迁移旧明文，兼容旧版密文；Windows 旧产品目录迁移保留受系统保护的加密上下文。暂时解密失败时保留密文和自动连接偏好，可重试恢复，不要求立即重输密码。
- **保存失败保持原状态**：先验证并完成原子写入，再更新内存、会话和守护状态；系统自启动设置失败时处理回滚并展示实际状态。
- **首次引导与弹窗**：记住密码默认不勾选，可仅本次使用或跳过；补齐焦点限制、Esc 关闭、关闭后焦点恢复及临时输入清理，更新提示等待其他弹窗结束。
- **隐私**：快照、活动日志和诊断包不含密码或密文。系统加密不可用时，新密码仅本次使用，不保存明文；历史目录或备份中的明文不自动清理。

认证协议、地址自动发现与缓存、自动重试提交规则和液态玻璃布局保持现有行为。本地加密不能保护 HTTP 认证链路的服务器身份和传输安全；系统账户或密钥损坏、迁移到其他系统用户时可能无法恢复原密文。

验证覆盖单元测试、发布流程检查、类型检查、Windows 本机模拟认证、连续三次 Electron 重启自动连接、断线重连、旧凭据迁移、保存失败和弹窗键盘操作。测试使用隔离数据，未读取真实账号或向真实校园网提交认证。macOS 安装包由对应架构 runner 构建，真实设备的钥匙串、登录项和校园认证仍需实机验证。

下载后可用随版本提供的 `SHA256SUMS.txt` 校验；源码提交与平台构建信息见 `build-info.json`。安装说明见 [使用指南](usage.md)。
