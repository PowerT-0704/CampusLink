# 岚连 Campus Link · CDUTYB 专版 v1.4.2 使用指南

面向 Windows 和 macOS 的校园网认证工具，使用 Electron、React 和 TypeScript 构建。v1.4.2 默认启用液态玻璃外观，可随时切换经典界面；提供连接状态、系统托盘、可配置的开机自启动，以及通过 JSON 导入的校园网连接方案。

默认选中成都理工大学（宜宾校区）的锐捷 ePortal Web 方案；贵州轻工职业大学（Dr.COM）与四川大学方案位于“更多内置方案”中，也可搜索或导入其他学校的匹配 JSON 方案。内置方案优先通过 `http://www.msftconnecttest.com/redirect` 只读探测当前网络的真实认证地址，原有学校地址保留为已知回退入口。本工具是独立的校园网辅助工具，与学校或认证服务商没有官方隶属关系。

专版维护者：**[PowerT-0704](https://github.com/PowerT-0704)** · 上游作者：**[NingMeng123](https://github.com/65658dsf)**

[上游在线使用文档与方案制作教程](https://campuslink.xzncraft.cn/)（上游版本说明与本专版存在差异，请以本指南及 [v1.4.2 发布说明](releases-v1.4.2.md)为准。）

本仓库 [CampusLink](https://github.com/PowerT-0704/CampusLink) 保存专版桌面客户端源码、认证适配器和自动化测试；[`site/`](../site/README.md) 提供独立静态项目官网。上游独立仓库 [CampusLinkPages](https://github.com/65658dsf/CampusLinkPages) 保存上游 Vue 文档网站源码。

## 安装和首次连接

在本项目 [v1.4.2 GitHub Releases](https://github.com/PowerT-0704/CampusLink/releases/tag/v1.4.2) 按系统和处理器选择安装包：

```text
Campus-Link-Glass-Setup-1.4.2.exe    Windows x64
Campus-Link-1.4.2-mac-x64.dmg        Intel Mac
Campus-Link-1.4.2-mac-arm64.dmg      Apple Silicon Mac
```

macOS 同时提供相应架构的 ZIP。DMG 打开后将应用拖入“应用程序”，再从该目录运行。默认构建未配置开发者签名或 Apple 公证，系统可能阻止打开；请核对来源并按照系统提示处理，不要关闭系统安全保护。未签名或未公证时，macOS 开机自启动也可能不可用。macOS 打包与系统行为仍需对应设备验证，不能将 CI 产物视为已完成校园网实测。

1. Windows 运行安装程序并选择安装位置：浏览选择父目录时会自动追加 `Campus Link` 文件夹，手动输入的目录也会在安装前补全，已以该名称结尾时不会重复添加；macOS 安装到“应用程序”，然后打开“岚连 Campus Link”。
2. 先在系统中连接校园 Wi-Fi，或插入校园网网线。本工具完成网络认证，不代替操作系统的无线网络连接功能。
3. 新安装默认已选中成都理工大学（宜宾校区），无需填写认证地址或选择网络服务。其他学校到“连接方案”搜索并切换，或导入匹配 JSON 方案；贵州轻工与四川大学方案也可在“更多内置方案”中展开。
4. 应用会先检测当前认证状态；以后启动沿用已保存的方案。已认证时直接显示在线状态和会话详情，无须重复登录。v1.4.2 首次引导仍允许输入并保存当前账号密码，已在线时保存凭据不会改变当前会话，也可稍后通过“管理账号密码”设置。
5. 尚未认证时，输入学校提供的账号、密码，按需勾选“记住密码”，再点击连接按钮。使用系统加密保存后，重启可继续使用；开启启动自动连接需要先保存加密凭据。首次引导默认不勾选记住密码，也可仅本次使用或跳过。

需要结束认证时，在应用内点击“注销校园网”，或使用托盘菜单中的“断开认证”。退出应用与注销校园网是两个独立操作，退出应用不会自动断开现有认证。

## 主要功能

| 功能 | 使用方式 |
| --- | --- |
| 连接和断开 | 在连接概览提交认证，已连接时可注销 |
| 状态查询 | 启动时检测；网络守护开启后按设定间隔检查，也可手动“检测网络” |
| 认证地址发现 | 内置 Dr.COM / 锐捷方案优先只读探测当前校园网入口，未识别到门户时回退已知学校地址 |
| 开机自启动 | 在“连接偏好”或“应用设置”中开启；需要安装后的桌面版本，macOS 还受签名及系统登录项许可影响 |
| 启动后自动连接 | 先保存账号密码，再单独开启；会先查询认证状态 |
| 断线自动重连 | 默认开启，成功认证或确认在线后开始守护；明确离线时用可用凭据尝试恢复 |
| 检测间隔 | 应用设置中配置 5–3600 秒，新用户默认 10 秒，已有设置保持原值 |
| 网络变化检测 | 本机 IPv4 地址集合变化时触发静默状态检查，未选方案时不请求认证服务器 |
| 托盘守护 | 悬浮显示本机 IP 与在线时长，菜单支持暂停和恢复守护 |
| 关闭到托盘 | 默认开启，可在应用设置中关闭；Windows 使用系统托盘，macOS 使用菜单栏图标 |
| 方案搜索与选择 | 在“连接方案”搜索学校、方案名称或协议，选择后才启用对应认证流程 |
| 外部方案 | 在“连接方案”导入 JSON、选择方案或移除外部方案；移除当前外部方案后回退宜宾默认方案 |
| 导出当前方案 | 每张方案卡片点击“导出 JSON”，保存该方案完整配置；内置方案也可导出为可重新导入的副本 |
| 方案示例 | “连接方案”中的“导出方案示例”（HTTP）或“导出锐捷示例” |
| 活动日志 | 查看、按级别筛选和复制本次运行的最近 100 条记录；点击“查看响应”展开请求与服务器响应详情 |
| 清除密码 | “应用设置 → 账号与隐私 → 清除密码” |
| 密码管理 | 使用系统加密保存；重启后自动恢复，已在线时也允许保存；系统暂不可读取时保留密文并提供重试 |
| 界面外观 | 新安装默认液态玻璃；“应用设置 → 界面外观”可切换经典，保留已有外观偏好；Win11 22H2+ 支持系统 Acrylic 桌面透视，其他平台回退应用内玻璃 |
| 诊断导出 | 应用设置中导出脱敏诊断 JSON，包含应用、网络概况与本次运行日志 |
| 开发日志 | 查看项目版本记录与开发者信息 |
| 检查更新 | 正式安装版启动时检查 GitHub 正式发行版，也可在“应用设置 → 软件更新”手动检查；发现新版后展示更新内容并前往 Releases 下载 |

已有选定方案时，每次启动都会先进行只读状态检查，无需保存账号密码，也无需开启启动后自动连接。断线自动重连默认开启：成功认证或检测到在线后，按设定间隔检查；仅在服务器明确返回离线时尝试重连，超时、HTTP 错误或未知响应不会触发认证。守护启用且未暂停时，返回窗口或系统唤醒也会刷新状态，连续刷新间隔至少 5 秒。托盘暂停守护不会注销当前认证，恢复后继续检查。

“开机自启动”和“启动后自动连接”默认关闭，分别控制启动应用和启动时提交认证。只开启自启动不会替你登录。启动后自动连接仅在启动检查确认未认证时登录；已在线则跳过，状态查询失败则停止本次启动认证。

“断线自动重连”独立控制持续守护，可使用本次成功连接留在内存中的密码，或本机已保存的密码；没有可用凭据时只检测并提示手动连接。手动注销立即暂停守护，再次手动连接成功后恢复。关闭自动重连会停止周期检测；检测间隔修改后按新值运行。退出应用会停止守护，但不会替你注销校园网。

认证地址发现不会向 Microsoft 提交账号密码。正常访问探测地址后跳转到 MSN、Bing 或返回普通网页，不代表已经通过校园网认证；应用只使用符合当前方案协议特征的真实门户进行认证和状态检查。没有发现新入口时，优先复用本次运行中已识别的来源，没有缓存则使用方案的已知入口。缓存不保存临时 `queryString`、MAC 或设备参数，退出后不持久化。

## 检查软件更新

在“应用设置 → 软件更新”点击“检查更新”，可查看当前版本、检查结果和检查时间。发现更新时会弹出新版本说明，可以前往 Releases 下载或选择“稍后再说”；同一版本在本次运行中只自动提示一次，仍可从设置页手动检查并查看更新内容。

正式安装版启动时会自动查询 `PowerT-0704/CampusLink` 的最新正式 Release，成功连接校园网后也会重试检查。开发模式不自动联网检查。草稿和预发布版本不会作为更新推送；比较按版本号的数字分段进行。网络不可达、超时或 GitHub 限流会显示检查失败，不会误报已是最新。

更新检查不上传校园网账号密码，不自动下载安装或执行远程内容；更新说明按纯文本展示，下载按钮只打开本仓库的 HTTPS Releases 页面。普通网络失败后 5 秒可重试，正常检查至少间隔 60 秒；受到限流时会适当延长等待。

## 贵州轻工职业大学适配情况

2026-10-11 已核验以下内容：

- 认证页及其引用脚本可以访问。
- 当前配置为 Dr.COM 本地认证，服务参数为 `R3=1`，标签“校园网”。
- 当前账号不需要自动附加运营商后缀或旁路认证前缀。
- `/drcom/chkstatus` 可返回结构化的认证状态。

登录 `/drcom/login`、注销 `/drcom/logout` 的参数来自当前页面脚本。本轮经用户授权进行了真实登录请求诊断：旧参数顺序返回 HTTP 203 和 `Bad request(2)`；调整为网页参数顺序后返回 HTTP 200 JSONP，业务结果为 `error5`、`waitsec < 3`。用户另提供了同一参数顺序、`lang=en` 且 `result=1` 的成功抓包。v1.0.2 已对齐该请求顺序，并刻意保留网页请求中的两个 `lang=en` 参数。

内置适配在请求被接受后再次查询状态，以确认认证或注销结果。本轮始终保留原有在线会话，未执行真实注销，也未验证断网后首次登录。其它校区或运营商配置仍需实际使用验证；本项目不宣称覆盖所有学校和所有 Dr.COM 部署。详细证据与限制见 [认证协议核验](portal-protocol.md)。

## 密码与本地数据

v1.4.2 改用系统加密保存凭据。勾选“记住密码”后，应用通过 Electron `safeStorage` 使用系统加密保存密码，并在保存前验证密文能够还原。正常退出、重新启动和兼容升级后会自动恢复，无需每次输入。首次引导默认不勾选记住密码；不勾选时，密码仅在本次运行中使用，也可跳过引导，之后不再重复弹出。

账号、连接方案和偏好保存在 Electron 的 `userData` 目录；Windows 下通常为 `%APPDATA%\岚连 · CDUTYB 专版（液态玻璃版）\settings.json`。密码只以系统密文写入该文件，密码与密文均不返回给界面快照，也不写入活动日志或诊断导出。解密后的密码只在主进程内存中复用，界面刷新不会重复解密。此次保留应用标识及数据目录；首次启动可能从旧版目录迁移设置。

“最近活动”和“活动日志”中的“查看响应”可展开错误摘要、错误代码及各次请求的方法、去掉查询参数的 URL、HTTP 状态码、响应类型、耗时和脱敏响应正文。每次请求的正文最多保留 16 KiB，超出时显示截断提示；正文以纯文本展示，可点击“复制详情”。诊断记录只保留在当前进程内存中，不写入本地设置或日志文件；关闭应用后清除，主动复制的内容会进入系统剪贴板。

旧明文凭据会在应用正常启动时迁移为系统密文，旧版加密凭据继续兼容。Windows 从旧产品目录迁移加密凭据时，会在系统加密初始化前保留相应的受系统保护的加密上下文；已有目标设置或不同的加密上下文不会被覆盖。如果系统加密暂不可用，新密码只在本次运行中使用，启动自动连接不会启用；旧明文成功移除后也可点击“加密保存本次密码”重试，无需重新输入。迁移写入失败时保留原文件并明确提示，历史目录或备份中的明文不会自动清理。

已保存的密文因系统暂时锁定或解密失败而不可读取时，应用会保留密文及原自动连接偏好，并暂停凭据提交。在连接概览或“应用设置 → 账号与隐私”点击“重试读取已保存密码”，系统恢复后可继续自动连接。不会因一次读取失败而清空密码；系统账户、系统密钥确实改变或密文损坏而无法恢复时，才需要重新输入。Windows 系统加密不能防止同一登录用户下的恶意程序访问。

配置保存失败时不会更新账号、密码、会话或守护状态；系统自启动回滚失败会提示核对系统状态。清除密码会同时移除本次运行缓存并关闭启动自动连接；更换方案会移除旧凭据。通过密码管理更换账号时保存新凭据并关闭启动自动连接，当前已登录会话不会因此被注销。

本地存储策略不改变学校认证协议的传输方式：内置方案的认证入口使用 HTTP；锐捷 ePortal 适配器按协议对密码进行 RSA 变换，不等同于 HTTPS 传输。外部连接方案同样会向配置中指定的认证地址提交账号密码，应先核对学校提供的地址。卸载默认保留本地设置；如需移除已保存凭据，请先在应用中清除密码。

## 扩展其它校园网

应用支持三类**声明式 JSON 方案**：`http` 用于固定 GET/POST 接口与响应规则；`drcom` 复用应用受控的 Dr.COM Web 适配器；`ruijie` 使用受控的锐捷 ePortal Web 适配器，自动获取当前认证参数并完成 RSA 密码变换。它不加载或执行导入文件中的 JavaScript、Python 或可执行程序。

1. 固定 HTTP 接口点击“导出方案示例”，或复制 [custom-campus.example.json](../examples/custom-campus.example.json)；锐捷 ePortal 点击“导出锐捷示例”，或复制 [ruijie-campus.example.json](../examples/ruijie-campus.example.json)。
2. 根据学校真实认证接口修改地址、请求参数和响应规则。示例中的 `.invalid` 域名是占位符，不能直接登录；其中运营商选项也只是格式示例。
3. 点击“导入连接方案”，选择 UTF-8 JSON 文件。
4. 在列表中点击“使用此方案”，填写账号和自定义参数，再按需检测、连接。

单文件最多 64 KB，可导入最多 30 个外部方案。导入不会自动认证，也不会自动覆盖相同 ID 的旧方案。通用字段与 HTTP 请求规则见 [扩展方案指南](plugin-guide.md)；锐捷入口发现、抓包、服务编码、公钥配置和完整制作步骤见 [锐捷方案教程](ruijie-guide.md)。

每张方案卡片的“导出 JSON”会保存完整声明式配置，包括自动发现设置、HTTP 请求规则或锐捷公钥。导出内置方案时会生成带 `-copy` 后缀的外部 ID，可以作为副本重新导入；外部方案保留原 ID，再次导入前需要修改 ID 或移除旧副本。导出不包含应用保存的账号、密码、当前字段选择、登录会话或运行期间发现的临时地址。文件仍保留方案作者声明的固定地址、默认值和请求模板，分享前请确认其中没有自行写入的个人信息。

内置四川大学方案参考上游 ePortal Web 实现，支持确认在线、登录、注销及现有网络守护流程。它不是所有锐捷校园网的通用配置，也不支持锐捷 802.1X 客户端认证；其他学校需要替换入口、跳转源、服务值和公钥。当前只完成源码对照与本地模拟服务验证，**未在四川大学真实网络验证**。来源提交和第三方许可见 [锐捷方案教程](ruijie-guide.md#参考来源与许可) 与 [第三方声明](../assets/licenses/README.md)。

`drcom` / `ruijie` 方案可使用顶层 `portalDiscovery: { "url": "http://www.msftconnecttest.com/redirect" }` 开启网络入口发现；内置方案和锐捷示例默认配置。`homepage` 仍是必须填写的已知回退地址，`ruijie.discoveryUrl` 保留为与它同源的已知发现入口。发现功能不会自动识别所有校园网协议，也不会替你选择其他学校的服务或 RSA 公钥。v1.1.2 的完整更新与验收边界见 [发布说明](releases-v1.1.2.md)。

## 本地开发

使用 Node.js **22.12 或更高版本**及 npm，在项目目录执行：

```powershell
npm ci
npm run dev
```

首次安装依赖和首次打包需要下载 Electron、构建工具等文件。`npm run dev` 启动 Vite 和 Electron 桌面窗口，开发模式不注册开机自启动。

如只想调整和查看界面：

```powershell
npm run dev:web
```

打开终端显示的本地地址。浏览器预览没有桌面桥接，不能执行认证、保存密码、导入本地方案或配置自启动，不会展示伪造的连接成功状态。

| 命令 | 作用 |
| --- | --- |
| `npm run dev` | 启动桌面开发环境 |
| `npm run dev:web` | 仅启动浏览器界面预览 |
| `npm run typecheck` | TypeScript 类型检查 |
| `npm run build` | 类型检查并构建界面，输出 `dist/` |
| `npm start` | 使用已有 `dist/` 启动 Electron |
| `npm test` | 运行本地自动化测试 |
| `npm run test:desktop` | Windows 构建后运行桌面集成检查；仅向本机模拟服务认证 |
| `npm run test:release` | 无网络检查发布标签、签名配置、产物完整性与校验和 |
| `npm run pack:win` | 构建可直接运行的 Windows x64 应用目录 |
| `npm run dist:win` | 构建 Windows x64 NSIS 安装程序 |
| `npm run dist:mac` | 在 macOS 构建 x64、arm64 各自的 DMG 和 ZIP |
| `npm run dist:mac:x64` / `npm run dist:mac:arm64` | 在 macOS 仅构建指定架构 |

Windows 打包示例：

```powershell
npm ci
npm test
npm run dist:win
```

v1.4.2 Windows 安装程序输出为 `release/Campus-Link-Glass-Setup-1.4.2.exe`；只构建应用目录时，可运行程序位于 `release/win-unpacked/`。macOS 打包必须在 Mac 上运行，对应的 DMG/ZIP 也输出到 `release/`。所有打包命令明确禁用自动上传。`dist/` 是界面构建产物，不能替代完整桌面程序。

自动化测试使用本机模拟服务和模拟凭据，覆盖方案校验、HTTP 编码、JSONP 解析、响应判定、系统加密、旧凭据迁移、读写失败恢复和自动连接约束。`node scripts/smoke-credentials.cjs` 额外验证原生加密跨进程重启、自动连接、断线重连及弹窗键盘操作。工作路径包含 `#` 时，可用 `node scripts/build-acceptance.cjs` 构建界面，不修改现有构建配置。测试不会向真实校园网提交认证或注销，也不能替代真实账号的连接验收。独立官网与本版本同步维护，见 `site/`。

## GitHub Actions 自动发布

推送到 `main` 或提交 PR 会运行 Linux 单元测试、发布流程检查和界面构建。发布版本时，将 `package.json` 与 `package-lock.json` 的版本一起更新并合入 `main`，再推送匹配的标签，例如 `v1.4.2`。工作流确认标签提交属于 `main` 后，分别在 Windows、Intel Mac 和 Apple Silicon Mac runner 构建；全部成功后由独立发布任务统一上传到 GitHub Releases。

普通提交不会创建 Release。也可在 Actions → Desktop CI and Release → Run workflow 中选择 `main`，输入已存在且版本匹配的标签重试。没有 Apple secrets 时仍会生成未签名产物；配置完整证书及公证凭据后才启用对应步骤。完整配置、发布命令和失败恢复见 [发布指南](releases.md)。

## 常见问题

**提示无法访问认证服务器**：先检查 Windows 是否已接入校园网络，再打开认证页。如果浏览器也无法访问，优先检查网络接入和校内服务。状态查询失败代表暂时无法确认认证状态，不代表已成功断开。

**提示认证失败**：检查账号、密码和所选网络类型。学校的欠费、账号停用、设备限制等情况需要在认证页或通过校园网服务渠道处理。

**提示服务器响应无法识别**：在“最近活动”或“活动日志”点击该条记录的“查看响应”，检查 HTTP 状态和服务器返回的文本；“复制详情”会复制已脱敏的诊断信息。若服务器返回了网页或错误文本，应用不会将其当作认证成功。没有响应详情的错误可通过“查看详情”查看摘要。

**自启动开关无法开启**：开发模式和浏览器预览不能注册自启动。Windows 安装后检查“启动应用”；macOS 从“应用程序”运行，并检查系统的“登录项”。未签名或未公证的 macOS 构建可能无法注册登录项。

**无法开启自动连接**：先在连接页面勾选记住密码并提交账号，或通过“管理账号密码”保存凭据，再开启自动连接。持久保存需要系统加密可用；暂不可用时可仅本次使用，恢复后点击“加密保存本次密码”重试。建议先确认手动认证成功。

**导入失败**：确认文件为有效 JSON，ID 没有重复，接口和认证页同源，模板变量已声明，成功与失败规则完整。具体要求见 [扩展方案指南](plugin-guide.md)。

**关闭后仍在运行**：这是默认的关闭到托盘行为。右键系统托盘图标，选择“退出岚连”即可退出。
